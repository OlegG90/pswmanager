# Android design

Mockups of PswManager for Android from Claude Design, in the Classical design system. HTML mockups,
not app code: nothing here is built or shipped.

- `PswManager Android.dc.html` — static screens at the Samsung Galaxy S24 Ultra viewport
  (384 × 832 dp): onboarding (Dropbox or a local file, then the folder for the working copy),
  unlock, list with search, drawer with groups and tags, entry view, sync status and every
  status-line state, settings. Open it in a browser; it loads `support.js` from this folder and the
  design system from `../_ds/`.

Content follows `docs/spec.md`: the fixed groups (All, Favorites, Expired, 2FA, Passkey, Templates,
Trash), tags with counts, the sync decision and its status texts, and the security settings with their
defaults. Icons are Lucide, as the design system asks.
